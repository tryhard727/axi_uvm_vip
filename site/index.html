VALID and READY are independent. A transfer occurs only at a rising clock edge when both are high. This is an illustrative protocol timing trace, not a waveform captured from a simulation.
AT A GLANCE

Three things to track

01 / ADDRESS

AxADDR + AxSIZE

AxADDR is the start byte address. AxSIZE encodes bytes per transfer as 2AxSIZE.

02 / LENGTH

AxLEN is zero-based

AxLEN is the number of transfers minus one. Total beats = AxLEN + 1 (AXI3 supports up to 16 beats).

03 / WRITE DATA

WSTRB selects lanes

Each WSTRB bit qualifies one byte lane on WDATA. A zero bit means that byte lane is not written.
